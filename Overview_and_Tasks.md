## 4. Summary of Task Requirements

### Task 1: CGPA Calculator
- Input total number of courses.
- Take grade and credit hours for each course.
- Calculate grade points ($Grade \times Credit\ Hours$) and total credits.
- Compute semester GPA and cumulative CGPA.
- Output detailed course summaries and final CGPA.

### Task 2: Login and Registration System
- User Registration (Username & Password input validation, duplicate check).
- File persistence (Store user credentials securely in file/database).
- Login Authentication (Read file, verify credentials).
- User feedback (Success/Error handling messages).

### Task 3: Sudoku Solver
- Represent $9 \times 9$ grid as a 2D matrix.
- Implement backtracking recursive algorithm.
- Validate Sudoku rules (Row, Column, $3 \times 3$ Box constraint checks).
- Solves grid automatically; (Optional GUI extension).

### Task 4: Banking System
- Class design: `Customer`, `Account`, `Transaction`.
- Core features: Account creation, Deposits, Withdrawals, Fund Transfers.
- History tracking: Record transaction logs and display account statements/balance.
